┌──────────────────────────────────────────────────────────────────────────────┐
│ HOW TO GET STARTED                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

1. READ DOCUMENTATION (5 minutes)
   • Start with: INDEX.md (navigation guide)
   • Then read: README.md (overview & features)
   • Then check: QUICK_START.md (setup steps)

2. SETUP DATABASE (5 minutes)
   • Install PostgreSQL + TimescaleDB
   • Create user and database
   • Run migration: 001_init_schema.sql

3. BUILD & DEPLOY (10 minutes)
   • Build agent:   cd agent && cargo build --release
   • Build server:  cd ../server && cargo build --release
   • Build dashboard: cd ../dashboard && npm install && npm run build
   • Run installer for your platform (Windows/Linux/macOS)

4. VERIFY OPERATION (5 minutes)
   • Login to dashboard at http://localhost:5173
   • Check devices appear in 5-30 seconds
   • View activity, inventory, USB events, and alerts
   • Monitor logs and database for data

5. DEPLOY TO PRODUCTION (1 hour)
   • Review .env configuration
   • Set up HTTPS on server
   • Configure firewall rules
   • Deploy to production machines
   • Setup monitoring and alerting
